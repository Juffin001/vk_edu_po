# vk_edu_po
Проект для технопарка, курс: "Методы управления разработкой ПО". Автор: Магдеев Ильяз Рамилович, группа: ИУ6-35Б

Elevator Pitch:
Люди, которые хотели бы читать книги, этого не делают. Мы предоставляем удобный сервис для нахождения компании по общим интересующим книгам, общения в процессе и после чтения, общие дедлайны (которые устанавливают сами люди). В результате люди вместе постепенно читают и обсуждают произведения, подобно тому, как компания друзей каждые выходные обсуждает новый сериал, и из-за чувства причастности к компании, люди дочитывают книги до конца. Компания зарабатывает на подписке, которая позволяет самому создавать “комнаты” с чтением конкретных книг, а не только присоединяться к уже существующим, а также коллабам с сервисами по типу Литреса, производителями электронных книг и кофейнями.
